# wRTC Bridge Monitor (Deprecated)

> **Deprecated — do not deploy.** The wRTC bridge is disabled. RTC is earned for contributions and spent on services in the ecosystem; there is no off-ramp. See [Earn & Spend RTC](https://github.com/Scottcjn/rustchain-bounties/blob/main/docs/EARN_AND_SPEND.md).

This static page monitored the wRTC bridge and displayed third-party market data. Both functions are retired.

## Status

- **Not supported.** Whether any instance is still running is not known; it should not be.
- The source (`index.html`, `dashboard.html` and supporting files in this directory) is kept in the repository so that any existing deployment can be identified and shut down. It is not removed silently.
- If you operate an instance, please stop it.
- Do not open bounties or pull requests that extend this component.
