## Description
RustChain’s public API documents miners by hardware class and includes a PowerPC G4 example with a 2.5x antiquity multiplier. This short explains what that number does — and does not — mean, and why RustChain treats preserved physical hardware as a distinct DePIN resource.

Read the public project and API documentation:
- https://rustchain.org
- https://github.com/Scottcjn/Rustchain

No guaranteed earnings or speed claims are made. The 2.5x figure is the documented antiquity multiplier in the public API example, not a compute-performance benchmark.
