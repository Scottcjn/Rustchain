# RustChain OTC Bridge (Deprecated)

> **Deprecated — do not deploy.** The wRTC bridge is disabled. RTC is earned for contributions and spent on services in the ecosystem; there is no off-ramp. See [Earn & Spend RTC](https://github.com/Scottcjn/rustchain-bounties/blob/main/docs/EARN_AND_SPEND.md).

This community contribution implemented an over-the-counter order book for RTC. RustChain does not offer or endorse any way to exchange RTC for other assets.

## Status

- **Not supported.** Whether any instance is still running is not known; it should not be.
- The source (`otc_bridge.py`, `static/`, `contracts/` and tests; see [SETTLEMENT.md](SETTLEMENT.md) for the historical settlement design) is kept in the repository so that any existing deployment can be identified and shut down. It is not removed silently.
- If you operate an instance, please stop it.
- Do not open bounties or pull requests that extend this component.
