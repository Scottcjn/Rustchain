# wRTC Price Ticker Bot (Deprecated)

> **Deprecated — do not deploy.** The wRTC bridge is disabled. RTC is earned for contributions and spent on services in the ecosystem; there is no off-ramp. See [Earn & Spend RTC](https://github.com/Scottcjn/rustchain-bounties/blob/main/docs/EARN_AND_SPEND.md).

This bot was a community contribution that reported third-party market data for wRTC. RustChain official materials no longer reference market prices, and the `$0.15` reference rate is an internal accounting unit, not a market price.

## Status

- **Not supported.** Whether any instance is still running is not known; it should not be.
- The source (`bot.py`, `Dockerfile`, `requirements.txt`) is kept in the repository, unchanged, so that any existing deployment can be identified and shut down. It is not removed silently.
- If you operate an instance of this bot, please stop it.
- Do not open bounties or pull requests that extend this bot.
