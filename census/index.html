            How to get on the census

            1. Run the RustChain miner on the machine so it attests to the network.
            2. Take a photo that shows the machine, its serial plate, and a sheet of paper with this written by hand: RTC CENSUS <your GitHub handle> <today's date>
            3. Submit it with the census submission form on GitHub.
            4. A maintainer reviews the photo and adds the machine to the Verified list.

            Listing is free and earns no RTC. The census is a preservation record.

            Privacy: the census page never shows wallets, miner IDs or IP addresses. A display name is optional; you can stay anonymous. GitHub issues are public, so your photo and handle are visible on the submission itself (you may cover all but the last 4 characters of the serial). Ask in an issue to have an entry removed.
