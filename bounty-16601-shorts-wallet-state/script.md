# Script — “Pending Is Not Paid”

Target length: 45–55 seconds.

## Narration

**Hook (0–5s)**
“Your wallet says a transfer exists. That does **not** always mean the money is settled.”

**Body (5–42s)**
“RustChain’s public wallet history exposes transfer state directly. A record can be `pending`, `confirmed`, or `failed`, and it can include both `confirmed_at` and `confirms_at`. Signed wallet transfers are also documented as entering a pending phase before confirmation. So if you are tracking earnings, a pending transfer is evidence of a transfer in progress — not realised profit yet. The safer ledger rule is simple: record the claim, record the pending payment, and only move it into settled earnings when confirmation is actually visible.”

**Close (42–55s)**
“That distinction sounds boring, but it is what keeps an earnings dashboard honest. Pending is promising. Confirmed is paid.”

## On-screen text
- “PENDING ≠ SETTLED”
- `/wallet/history`
- `status: pending | confirmed | failed`
- `confirmed_at`
- `confirms_at`
- “Claim → Pending → Confirmed → Settled”

No statement in this script should be read as a guarantee of payment timing or value.
