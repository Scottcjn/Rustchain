## Description
A short, source-grounded explainer of RustChain wallet transfer states using the public API reference. It covers `/wallet/history`, `pending` / `confirmed` / `failed`, confirmation timestamps, and why an honest earnings ledger should separate pending payments from settled earnings.

RustChain repository: https://github.com/Scottcjn/Rustchain
