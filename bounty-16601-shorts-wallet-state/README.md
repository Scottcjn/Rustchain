# RustChain Shorts Kit — “Pending Is Not Paid”

Package type: C — Shorts / clip kit for RustChain bounty #16601.

## One-line pitch
A <=60 second vertical explainer showing why a RustChain wallet transfer marked `pending` should not be treated as settled money, using the public `/wallet/history` response fields and signed-transfer confirmation model.

## Package contents
- `script.md` — narration and on-screen copy
- `capture-instructions.md` — exact 9:16 capture/edit instructions
- `metadata.md` — title, description, tags, hook
- `SOURCES.md` — claim-to-source map

This package is intentionally distinct from the earlier G4/antiquity short: it focuses on wallet state and settlement semantics rather than vintage hardware.
